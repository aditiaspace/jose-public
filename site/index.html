OPTION A

OpenCode + DeepSeek API

  1. Install OpenCode from its official guide and open a private folder. If another provider already works, keep using it.Pasang OpenCode dari panduan resminya lalu buka folder privat. Jika provider lain sudah berfungsi, tetap gunakan provider itu.
  2. For DeepSeek, create an account and API key on the official platform. Review pricing and balance/top-up information first.Untuk DeepSeek, buat akun dan API key di platform resminya. Tinjau harga dan informasi saldo/top-up terlebih dahulu.
  3. In a terminal, run opencode auth login, choose DeepSeek in the interactive provider flow, and enter the key there—not in chat, Jose files, or command arguments.Di terminal, jalankan opencode auth login, pilih DeepSeek melalui alur provider interaktif, lalu masukkan key di sana—bukan di chat, file Jose, atau argumen command.

OPTION B

DeepSeek Harness + DeepSeek API

  1. Install DeepSeek Harness using its official quickstart, then open its local interface.Pasang DeepSeek Harness mengikuti quickstart resmi, lalu buka antarmuka lokalnya.
  2. Create a DeepSeek API key on the official platform and review current prices and balance/top-up information.Buat API key DeepSeek di platform resmi dan tinjau harga serta informasi saldo/top-up terbaru.
  3. In Harness, open Settings → Models, choose DeepSeek, and enter the key in its provider setting. Do not paste it into a Jose conversation or project file.Di Harness, buka Settings → Models, pilih DeepSeek, lalu masukkan key pada pengaturan provider. Jangan tempel ke percakapan atau file project Jose.
Harness quickstart ↗Provider guide ↗
DeepSeek API usage may incur charges. Check current pricing, balance, and top-up rules on DeepSeek's own pages; there is no price guarantee here. Store the key only in your chosen harness. Jose never collects it.Penggunaan DeepSeek API dapat dikenakan biaya. Periksa harga, saldo, dan aturan top-up terbaru di halaman resmi DeepSeek; halaman ini tidak menjamin harga. Simpan key hanya di harness pilihan Anda. Jose tidak pernah mengumpulkannya.
